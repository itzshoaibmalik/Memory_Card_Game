# Memory Card Game 🎮

A modern, interactive memory card matching game built with HTML, CSS, and JavaScript. Test your memory skills with beautiful animations, sound effects, and multiple difficulty levels!

## 🌟 Features

- **Multiple Difficulty Levels**
  - Easy: 4x4 grid
  - Medium: 5x4 grid
  - Hard: 6x5 grid

- **Interactive Gameplay**
  - Score tracking
  - Move counter
  - Timer
  - Sound effects for card flips and matches
  - Confetti animation on winning

- **Customization Options**
  - Multiple background music tracks
  - Different card back designs
  - Theme selection (Neon Abyss, Sunset)
  - Background video support

- **User Features**
  - User authentication (Login/Signup)
  - Leaderboard system
  - Profile management

## 🎮 How to Play

1. Select your preferred difficulty level
2. Click on cards to flip them
3. Find matching pairs of cards
4. Complete the game with the least moves and time possible
5. Compete for high scores on the leaderboard
